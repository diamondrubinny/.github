# Getting help

1. **Read the README** of the project — installation and usage are documented there.
2. **Search existing issues** — your question may already be answered.
3. **Ask in Discussions** (where enabled) for questions, ideas and show-and-tell.
4. **Open an issue** for reproducible bugs, using the Bug report template.

Need a custom system, integration or paid support? → [rubinny.co.il](https://rubinny.co.il)
